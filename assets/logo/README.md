# Croptimizing logo

| File | Use it for |
| --- | --- |
| `croptimizing-logo-on-light.png` | Slides, documents, anything with a white or light background |
| `croptimizing-logo-on-dark.png` | Dark backgrounds (navy, as in the site header) |
| `croptimizing-logo-transparent.png` | Placing the logo on your own background (navy text) |
| `croptimizing-mark.svg`, `croptimizing-mark-512.png` | The four-parcel mark alone, transparent background |
| `croptimizing-icon.svg`, `croptimizing-icon-512.png` | App or favicon style icon (mark on a navy rounded square). The site's favicon is the same design: `public/favicon.svg` |

The SVGs scale to any size. The wordmark uses the Inter font, semibold.

Colors: navy `#0B3D91`, alfalfa green `#00805C`, water cyan `#00C2FF`, durum orange `#D55E00`.
The mark is four field parcels seen from above; the cyan one is water.

To redraw the PNGs after changing an SVG: `npx tsx scripts/render-logos.ts`.
Please do not pair the logo with NASA logos or mission patches.
